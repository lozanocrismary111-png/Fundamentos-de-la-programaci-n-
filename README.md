## reserva_cine.py.py
Programa que simula la reserva de asientos en una sala de cine representada como una matriz de 3 filas por 4 columnas. El usuario ingresa la fila y columna del asiento que desea reservar, el programa lo marca dentro de la matriz y muestra el estado completo de la sala utilizando bucles anidados para recorrer filas y columnas.

## Tarea semana 14

**Descripción del problema:**
Este programa resuelve un problema sencillo de la vida real: calcular el doble 
o el triple de un número ingresado por el usuario.

El programa utiliza una función llamada `calcular`, que recibe dos parámetros 
(`numero` y `opcion`) y, mediante una estructura condicional, determina si se 
debe calcular el doble o el triple del número. El resultado se devuelve mediante 
la palabra clave `return` y se muestra en pantalla usando `print`.

**Estructura del programa:**
- Función: `calcular(numero, opcion)`
- Parámetros: `numero` (valor a multiplicar), `opcion` (texto "doble" o "triple")
- Retorno: el resultado del cálculo
- Llamada a la función: dentro de `if __name__ == "__main__":`
